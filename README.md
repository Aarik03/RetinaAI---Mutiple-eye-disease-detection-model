# RetinaAI

Proposed Solution:
We developed an AI-based system to detect eye diseases using retinal fundus images automatically.
The system uses a deep learning model to classify eye conditions 
Detects multiple diseases using a single model Provides fast predictions with confidence score Web-based, user-friendly interface
Objectives:
Early detection of eye diseases Reduce dependency on specialists
Improve accessibility in rural healthcare Support doctors with AI assistance

This project RetinaAI develops an AI-based system to detect common eye diseases using retinal images. A user uploads a retinal eye image through a web interface, and the system automatically processes the image using a deep learning model. The model analyzes important patterns in the image and predicts the eye condition from multiple disease categories.

The system is designed to support early eye disease screening and assist in faster preliminary diagnosis. It can be useful in clinics, eye camps, and remote areas where access to specialists is limited. The project demonstrates a working prototype that shows how artificial intelligence can be applied to healthcare for improving accessibility and efficiency.
